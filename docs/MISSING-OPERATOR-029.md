# GRAFT-029 — MISSING OPERATOR FAMILY FORGE

A new **source-owned** finite program synthesizer to answer a **MOTIF-authored impossibility question**. Experimental branch stacked on GRAFT-028 #24 and retaining its original code/rights.

The native compiler `src/missing-operator-forge-029.mjs` generates genuinely new executable JS programs for a **typed guarded graph-addition** family. This family is not the earlier GRAFT-027 JSON numeric extraction family. It operates on declared synthetic graph facts with typed `owner`, `actor` and `target` roles and produces one proposed new fact, without executing a real action or editing any file.

It accepts a content-digested `motif.missing-operator.v0` inquiry that represents a bounded reachability impossibility under fixed MOTIF-002 verbs. The requested new predicate becomes a JSON-escaped constant in a closed executor template. It does **not** receive permission to execute in external systems.

Candidate synthesis searches three distinct guarded programs: existing `broken` prerequisite, `permits` prerequisite, or both. Positive training cases alone cannot distinguish these programs, but separate selection and negative examples eliminate both weaker candidates. A unique surviving candidate is returned as **held, unsigned source code** with a digest and rejected-variant receipts.

The target synthetic goal in the initial experiment is to add `('inspected','bike1')`, a predicate no original fixed MOTIF-002 rewrite adds. This represents a graph-planning vocabulary extension, **not** knowledge that an actual bicycle was inspected or consent of an actual person.

The generated operator is currently a fixed **single-effect guarded graph addition**. The new grammar is hand-designed, finite, and constrained; this is not open-ended coding or new mathematics. A conventional classical graph-rule induction system with the **same labeled examples** can learn an equivalent action. The comparator must be run in MOTIF; GRAFT cannot claim general advantage.

Original GRAFT tests, source checks, and held-output demonstration are in CI. No network, credentials, deployment, production installation, code merges, real people, or actual physical-world effects.
