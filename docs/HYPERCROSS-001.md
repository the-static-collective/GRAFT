# HYPERCROSS-001 — cross × cross × cross × cross
**Status: public/synthetic integration experiment. No survivor histories in CI.**

The point is to test one *single* consequential question passing through actual native runtimes already demonstrated separately, with explicit transitions and a verifiable HOLD at the far end. We deliberately do not merge GRAFT's independent donor branches.

## One concrete sequence

```text
Question (synthetic / public)
  ├─ Black Star native Ghost Cut: historical knowledge horizon
  ├─ MEMENTO native context: proposed/not-admitted relations
  ├─ GRAFT reconstruction: source-pinned proposal receipt
  ├─ Free Graph native Python: validated graph neighborhood
  ├─ JAR;VIS original Jar/doors: ATTEND without fixture participants
  ├─ planZ original PhaseLift + three frozen proposal shards: suggestions
  ├─ CANNON original Canon Field: trust pins absent → UNKNOWN
  └─ GRAFT LIVE-WORK-002 current public GitHub scout: dated fresh observations
           ↓ exact source summaries, no consent
      LOADOUT native Python binding: only local.file.write fenced
           ↓ explicit invocation, not authority transfer
      GRAFT native useful-work printer: real local HTML + hash receipt
           ↓ exactly these artifact bytes
      GHoT native reference-node executor: SHA-256 hash receipt
           ↓ bytes match independently checked digest
      reLATTE native opaque roundtrip: signed transport → RECEIVE → HOLD
           ↓ native receiver-local disposition; retry returns same crossing
      lemonPRESS original work-manifest schema: FORMING / admission PENDING
           ↓ only an editorial CANDIDATE, never publication
      webZ/JAR;VIS: local printable handoff, not an invented web deployment
```

The upstream six-head source reader currently contains a synthetic historical MEMENTO world graph. It is **not** a current Waseca or survivor case graph. The live scout reads *public GitHub only* and does not verify current organization/project adoption. GHoT hashes on the CI runner only; it does not schedule workloads across machines. reLATTE cryptographically verifies transport, not field truth. LemonPRESS is an **original schema read**, not a publishing runtime. webZ is a local handoff destination, **not** a deployed crossing. This is a serious integration test precisely because every failure of readiness remains visible.

## The test question and privacy

CI runs **only** the wholly synthetic, public question:
`What Waseca community grocery action can be prepared as a printable invitation?`

Private messages, custody details, phone XML, identities, witness statements, and child-specific information must **not** be passed in CI or to GRAFT's public issue/PR surface. A real visitor scenario can be tested **locally with its own operator**, but it must not go through a public service until actual privacy assessment and permission controls exist. Source-code openness does not grant third-party-data publication permission.

## Run it

Node >=22, Python >=3.11, Git, OpenSSL. Check out the pinned donor commits exactly as in `.github/workflows/hypercross-001.yml` into `donors/`. Install reLATTE runtime dependency in its separate checkout (`npm install --prefix donors/relatte --omit=dev --ignore-scripts`). Then:

```bash
node src/hypercross.mjs \
  --question "What Waseca community grocery action can be prepared as a printable invitation?" \
  --cut fixtures/early-cut.json --world same-room-a0 \
  --blackstar-root donors/black-star --memento-root donors/memento \
  --freegraph-root donors/free-graph --jarvis-root donors/jarvis \
  --planz-root donors/planz --cannon-root donors/cannon \
  --planz-garden-root donors/planz-garden --planz-table-root donors/planz-table \
  --planz-abundent-root donors/planz-abundent \
  --loadout-root donors/loadout --ghot-root donors/ghot \
  --relatte-root donors/relatte --lemonpress-root donors/lemonpress \
  --output /tmp/hypercross-new-occurrence
```

The output directory must **not exist**. Run CLI again with a different directory to create a new occurrence. Artifacts include `kit/field-kit.html`, `kit/work-plan.json`, `kit/work-receipt.json`, `hypercross-receipt.json`, and `lemonpress-candidate.json`. Native reLATTE local receiver secrets and GHoT runtime state are explicitly excluded from published CI artifacts.

## Acceptance

- All native source checkout commit pins match; any mismatch refuses.
- Synthetic Black Star future knowledge is refused before the downstream chain.
- Empty public research does not masquerade as current evidence.
- LOADOUT refuses public publication; only expressly requested local files may be created.
- GHoT hash matches the generated printable artifact digest.
- reLATTE produces a native signed RECEIVE + R3_HOLD, `semantic_effect:none`; idempotent replay.
- LemonPRESS manifest remains `forming/pending`, and no claim of publication slips through.
- CI artifacts show actual outputs; `people_contacted:0`, `real_world_fulfillment:NOT_ESTABLISHED`.
