# LIVE-WORK-002 — current sources to useful work

The original six-code-head native ATTEND-001 stack is retained. The new public source scout reobserves the current GitHub branch HEADs, pins each Markdown read to the newly observed exact commit, records source digests and notes failed reads. It also discovers source-branch leads beyond the preknown registry (up to 100 branches per allowlisted project), and inspects at most two additional relevant Markdown documents.

JAR;VIS now synthesizes a **local, printable 4-card NEED / OFFER / BUILD / RETURN work kit** from source-dated plans and a user's current question. It executes **a real local file write**, only with an explicit --build-kit output directory. This operation is not permission to publish, contact people, move money or act on a physical property.

Run from the branch with the nine pinned checkouts as shown in the CI workflow:

    node src/jarvis-initiative.mjs --question "What grocery step can be prepared?" --cut fixtures/early-cut.json --world same-room-a0 --blackstar-root donors/black-star --memento-root donors/memento --freegraph-root donors/free-graph --jarvis-root donors/jarvis --planz-root donors/planz --cannon-root donors/cannon --planz-garden-root donors/planz-garden --planz-table-root donors/planz-table --planz-abundent-root donors/planz-abundent --build-kit /tmp/graft-work-kit-002

Produces field-kit.html, work-plan.json and work-receipt.json. The directory must not exist; no overwrite or remote messages. Without --build-kit this CLI produces a JSON plan without filesystem writes.

Source-boundaries: whitelist of the-static-collective public GitHub repos; no open-web general search, no private connector reads, no trusted-signature pin inference and no current field-outcome claims. Branch HEAD observation is not owner-approved CANNON canon or proof of deployed software. A stored historical plan cannot claim live stewardship. GitHub API errors are explicit partial coverage, not an absence of work.

Future stages: consented human gates and restricted typed actions (approved publication, message, deployment) with independently verified receipts; public-service safety and abuse controls before running any public-facing agent.
