### What is real

- GRAFT's six native Black Star, MEMENTO, Free Graph, JAR;VIS, planZ, and CANNON sources still run at the original fixed pins.
- LIVE-WORK public GitHub research and a real printable kit from first chain are recomputed from public current source reads.
- A deterministic **audible file** is made from the *actual new kit SHA*. This is an audio adapter: no radio hardware, RF broadcast, or Morse decoding by a receiver.
- The ORIGINAL experimental GHoT LOADOUT media probe runs real `ffprobe` on those resulting WAV bytes.
- The ORIGINAL experimental reLATTE cross-project adapter independently checks GHoT task/receipt, all donor file hashes, original media hash, signs transport, issues local HOLD and verifies idempotent retry.
- A subsequent ORIGINAL GHoT Radio House experiment consumes a one-way hash of the held crossing into a *different* signed work request. Its local worker performs real incremental SHA-256 on public ASCII input and produces a signed verified result, with synthetic operator approval.
- A tampered previous source `verification.json` is refused before the Radio House receiver is initialized.

### What this is NOT

No real people are contacted, no survivor records are uploaded, no real hardware is leased, no radio link is activated, no actual partner authorized anything, and no private evidence is carried. Radio House has **fixture-only** power/media/consent readings on the CI host, not observation of a real broadcast station. The receiver's later signed work does **not** silently transform the original HOLD into an ADMIT.

Private sibling CI keys and SQLite rows are deliberately not published as artifacts. Public synthetic subset includes the printable kit and digest/verification summary. The previous source pin remains a separate public experimental branch; no project main branch is merged.

### Why this crossing matters

It proves actual output from one integrated stack can become source material for another independent original experiment *without* claiming that an event is true, a source is accepted, an owner has authorized publication, or anybody was helped. If the second runtime cannot handle the output, **record HOLD** rather than silently replace it with a simulation.

**Native instruction:** don't run this with Caroline/EV records, any survivor cases, real witnesses, phone XML, account identifiers, or secrets. Those need an actual local private execution environment, not public CI.
