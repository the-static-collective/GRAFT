The new loopback-only local UI is operated through node src/serve-live.mjs after setting the nine GRAFT_*_ROOT checkouts. It binds 127.0.0.1:7791; the browser asks actual on-demand GitHub-source questions and obtains an explicit one-use HTML question kit download. It has no accounts, external communications, remote writes, or deployment. Origin, Host, content type, payload size, exact paths, no-store, and one-local-query-at-a-time boundaries are enforced. This is a developer workstation tool, NOT an Abundent production endpoint.


The integrated local browser uses the original CLI pipeline at 127.0.0.1:7791 on human request. Optional environment GRAFT_LIVE_PORT can change the loopback port. Set GRAFT_*_ROOT variables to the pinned donor checkouts before running: node src/serve-live.mjs . A single-use, short-lived in-memory response ID binds the Download Kit button to the research receipt. The UI never sends messages, submits a post to GitHub or stores a public user account.
