# GRAFT-031 — A New Model Family After the Old World Becomes Impossible

A source-owned **bounded synthetic environmental transition model**. This is not a physical gate operator.

## Missing-model certificate

Original GRAFT-030's candidate modes (`move`, `copy`, `recolor`) never **remove blue obstacle cells**: movement leaves blue fixed, copying adds red, and recoloring can add blue. Thus blue obstacle mass is nondecreasing under any old-grammar sequence. The new synthetic before/after 9×8 PNG-cell pair exhibits **eight blue cells decreasing to six** while preserving the rigid red object. The old closed grammar cannot explain this observation.

The original MOTIF-009 four-world model only represents *stationary* 4-cell or 8-cell blue barriers. The new 6-cell scene lies outside that model family. **This certificate is relative to these finite declared grammars, not globally impossible.**

## What GRAFT actually generates

`src/world-model-031.mjs` receives a content-addressed, fully typed **synthetic** paired-image discrepancy and infers the two adjacent obstacle cells that disappeared. It compiles three distinct and actually executable JavaScript program families from a closed template: do nothing; remove the observed two-cell gate; remove every blue cell.

The generator tests all three against independent labeled training, selection and negative cases, selecting **only the two-cell environmental update**. The held-out red-object positions are distinct from training, but share the same small modeled gate coordinate. The generated code is not preinstalled, deployed or invoked on physical devices.

Its standalone event contract is deliberately explicit: `SIMULATED_ENVIRONMENT_GATE_OPEN`. The source refuses physical `REAL_PHYSICAL_GATE_COMMAND` inputs and refuses applying the gate-opening rule twice. It produces **hypothetical frames**, not external actions or authentic observations.

The generated JavaScript source is hashed and saved in a `graft031.world-model-induction.v0` held receipt. MIT/MOTIF-013 uses the original pinned GRAFT source rather than copying its implementation.

## Falsification

`test/world-model-031.test.mjs` checks that:
- the old model cannot decrease blue obstacle mass;
- the new observation truly removes exactly two vertically adjacent blue cells without changing red;
- all three candidate sources execute and differ;
- the two-cell model uniquely survives training, selection, negative tests;
- new held-out red placements work under the same synthetic geometry;
- unauthorized real-world events and double-opening both HOLD;
- changed or overbroad evidence, contradictory labels, new unsupported geometries and altered authority fail closed.

This generation remains narrowly authored **finite program synthesis**, and an equal-information classical hypothesis enumerator can match it. It does not create arbitrary new mathematics, invent live adapters, comprehend real photographs, interact with an environmental device, or authenticate a new physical observation.
