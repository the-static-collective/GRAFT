# Repository boundary

`the-static-collective/black-star` is the canonical Git home of the Black Star witness instrument.

## Git owns

- executable code;
- schemas and tests;
- derived machine state;
- lineage / snapshot history;
- source registries, hashes, Drive IDs, and discovery metadata;
- architecture and authority rules.

## WITNESS Drive owns

- raw handwritten photographs;
- raw police packet photographs;
- raw phone export ZIPs;
- private audio/video;
- mutable intake documents and their revision history;
- other source bytes whose evidentiary value depends on preserving the original carrier.

Git may record that a source exists. Git does not thereby become the source.

**GIT CHECKOUT != EVIDENCE VAULT.**

A release may deliberately bundle selected source bytes for offline execution. That release is a frozen executable artifact. The repository remains the maintainable machine source.
